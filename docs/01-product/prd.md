# StockMentor 产品需求文档

## 1. 用户问题

投资初学者往往知道一些零散术语，却不能把公司商业模式、三大财务报表、估值、竞争和风险联系起来，也缺少持续练习与复盘工具。StockMentor 通过结构化学习闭环解决这些问题。

## 2. 核心用户旅程

1. 用户注册并登录。
2. 仪表盘展示当前进度和下一步建议。
3. 用户进入课程中心选择课程。
4. 用户阅读课时并标记完成。
5. 用户参加章节测验。
6. 系统自动评分客观题。
7. 错误题目进入错题本。
8. AI 导师解释错误原因并使用苏格拉底式问题检查理解。
9. 用户重新练习错题。
10. 用户完成公司分析训练。
11. 用户记录虚拟投资决策、风险和退出条件。
12. 用户在事后复盘中比较原判断与结果。

## 3. 产品原则

- 学习优先于价格刺激。
- 风险教育优先于收益想象。
- 解释方法，不替用户做投资决策。
- 进度、正确率和复盘比模拟收益更突出。
- 页面不模仿证券交易终端。
- 不使用“稳赚”“必涨”“最佳买点”等语言。

## 4. 第一核心闭环

V0.2 至 V0.6 必须先形成：

注册登录 → 课程学习 → 测验 → 错题 → AI 解释 → 仪表盘建议

在该闭环实际通过测试前，不开发公司分析和虚拟投资日志。
