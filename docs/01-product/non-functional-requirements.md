# 非功能要求

## 安全

- 密码必须 BCrypt 哈希保存。
- JWT 密钥必须从环境变量读取。
- 用户私有资源查询必须按当前用户 ID 隔离。
- 日志不得记录密码、完整 JWT 或真实密钥。
- 生产环境响应不得暴露堆栈、SQL 和内部类名。

## 性能

- 普通列表接口使用分页。
- 数据库为高频过滤条件建立索引。
- V1.0 以单机部署为基线。
- 不在没有数据证明时提前引入复杂缓存。

## 可维护性

- Controller 不直接操作 Mapper。
- DTO、VO 和数据库实体分离。
- 每个模块有清晰边界。
- Flyway 迁移只新增，不修改已应用迁移。
- 关键业务规则有自动化测试。

## 可用性

- 前端提供加载、空数据和错误状态。
- 表单错误能定位到具体字段。
- 401 自动清理登录状态并跳转登录页。
- 页面支持桌面和常见平板宽度，移动端保持可用。

## 可观察性

- 后端日志包含请求追踪所需的基础上下文。
- 健康检查可以判断应用是否启动。
- 未知异常记录完整服务端日志。
