# 测试策略

## 测试层次

### 单元测试

验证纯业务规则和 Service 行为，使用 JUnit 5 与 Mockito。

重点：

- 认证规则
- 课程完成幂等性
- 下一课计算
- 客观题评分
- 错题状态变化
- BigDecimal 持仓和盈亏计算

### Web 层测试

验证：

- 请求参数校验
- HTTP 状态
- 统一响应
- 401 和 403
- JSON 字段

### 集成测试

验证：

- Spring Security 过滤链
- 用户 A 无法访问用户 B 数据
- Flyway 与数据库结构
- 测验提交事务
- 虚拟交易事务回滚

### 前端验证

- TypeScript 类型检查
- 生产构建
- 核心页面人工流程
- 401 状态处理
- 加载、空数据和错误状态

## 规则

- 关键业务规则先写失败测试。
- 测试名称应描述行为和条件。
- 不为了让测试通过而降低业务约束。
- 不依赖不可控的真实 AI 或实时行情。
