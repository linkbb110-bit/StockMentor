## 实现内容

- V3 创建课程、章节、课时、用户课时进度四表，seed 为 1 门《股票投资基础》、10 章、20 课时。

- 前端课程目录和安全 Markdown 阅读支持匿名访问；登录后从后端恢复完成状态。
- Dashboard 从有序课程列表选择第一门课程，直接展示后端进度与下一课，覆盖 loading、error/retry、0%、部分进度和 100% 完成状态。

## 问题与根因

1. 首次后端完整测试执行 221 tests、31 errors。根因是 4 个旧全应用测试排除了 MyBatis 自动配置，却未为 V0.3 Repository 的四个 Mapper 提供测试替身；补齐与既有 Security 测试相同的 `@MockitoBean` 后，原失败 31/31 和完整 221/221 均通过。
2. 首次 HTTP 注册返回 400。根因是 Windows PowerShell 5 客户端没有按 UTF-8 bytes 发送中文 JSON；显式 UTF-8 后注册 201，产品代码无需修改。
3. 临时 MySQL 首次 TCP 连接返回 1130。根因是 `--skip-name-resolve` 与仅有的 `root@localhost` 不匹配；只重启本次临时实例并移除该参数后成功，未修改系统服务。
4. 两次 HTTP 汇总脚本因 PowerShell 运算符优先级和 stderr 警告产生非零退出码；逐项输出均已保留，并以修正后的独立断言和真实浏览器结果复核为 PASS。
