## 范围

V0.4 完成 `Lesson → Quiz → 后端评分 → Result → Wrong Questions → MASTERED` 学习闭环。范围限于客观题、重复 Quiz Attempt、错题状态机及对应前后端体验；不包含 V0.5 AI Mock、Attempt History、题库 CMS、公司分析、虚拟投资或聚合 Dashboard。

## 数据库与初始化内容

- Flyway V4 创建 `question`、`question_option`、`quiz`、`quiz_question`、`quiz_attempt`、`quiz_answer`、`quiz_answer_option` 和 `wrong_question`。
- 为现有 20 个 Lesson 各创建 1 个已发布 Quiz，每个 Quiz 含 2 道原创客观题，共 40 题。
- 支持 `SINGLE_CHOICE`、`MULTIPLE_CHOICE`、`TRUE_FALSE`；多选答案以关联表标准化存储，不使用 CSV 或 JSON。
- 唯一约束、外键、检查约束和查询索引覆盖 Quiz-Lesson 一对一、题目顺序、答案唯一性与 `(user_id, question_id)` 错题隔离。

## 后端实现

- 公开 Quiz 查询批量读取题目和选项，不返回 `isCorrect`、`correctOptionIds` 或 `explanation`。
- 登录用户提交完整 Quiz，由 `ObjectiveQuestionScorer` 校验选择基数、Option 归属及 exact-set 正确性；每次合法提交创建新的不可变 Attempt。
- Attempt、Answer、AnswerOption 和 WrongQuestion 更新处于同一事务；持久化失败时整体回滚。
- Wrong Question 使用 `PENDING` / `MASTERED` 六状态转换规则；并发首次答错通过联合唯一约束和原子 MySQL upsert 防止重复与丢失计数。
- Wrong Review 复用相同评分逻辑，但不创建 Attempt；所有私有读取和修改只使用认证主体 userId。

## 前端实现

- 新增公开 `/lessons/:lessonId/quiz` 与受保护 `/wrong-questions` 路由。
- QuizView 支持三种题型、完整作答校验、匿名登录引导、pending 防重复提交、后端分数/逐题结果/解析、重新测验以及加载和提交错误恢复。
- WrongQuestionsView 每次按 PENDING 或 MASTERED 从后端读取状态，逐题维护选择、pending、结果和错误；状态转换后重新请求当前列表。
- Quiz 路由参数变化会重新加载并重置本地作答/结果，GET 与 submit 均使用 generation 防止旧异步响应覆盖当前页面。
- Lesson 增加“课后测验”入口，认证 Dashboard 增加“错题本”入口；Lesson completion 与 Quiz Attempt 保持独立。

## Security 与隔离

- Spring Security 仅精确开放公开 Course/Lesson/Quiz GET；公开请求携带无效或过期 Bearer Token 时跳过 JWT 解析。
- `/api/v1/me/quizzes/**` 与 `/api/v1/me/wrong-questions/**` 始终严格认证。
- 公开 Quiz 和初始错题列表不泄露正确答案或解析；日志不得记录完整 Token、密码、密钥、正确答案集合或完整提交负载。
- Attempt、错题列表和 Review 均按当前认证用户隔离，客户端请求不接受 userId。

## 遇到的问题与根因

- 首次完整后端测试为 284 tests、5 context errors：两个禁用 MyBatis 自动配置的旧上下文测试没有 mock V0.4 Repository 依赖的 Mapper。只补测试夹具后聚焦 5/5、完整 284/284 通过，业务代码未改。
- Maven 沙箱首次无法访问本地缓存/网络；在授权范围内使用现有 Maven 缓存和 Temurin 17 重新执行后通过。
- 临时 MySQL 首启时 `--skip-name-resolve` 使 `root@localhost` 不匹配 TCP 来源；只重启隔离实例并移除该参数。普通应用用户因 binlog/SUPER 限制无法创建失败 trigger，改由隔离实例 root 创建和删除，未修改全局配置。
- 过期 Token 首次校验脚本未从 PowerShell HTTP 异常的 `ErrorDetails` 读取响应体；只修正验证脚本取证方式，后端实际行为为预期的 401。
