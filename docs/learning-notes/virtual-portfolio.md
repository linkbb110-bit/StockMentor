# 虚拟投资组合学习笔记

## 1. 这个模块解决什么问题

让用户在不使用真实资金的情况下记录模拟买卖、决策理由、风险、退出条件和事后复盘，并学习成本与盈亏计算。

## 2. 为什么这样设计

V1.0 不接实时行情，用户手动输入学习模拟价格。这样避免行情授权、费用和接口稳定性问题，并把重点放在决策记录和风险管理上。

默认初始虚拟资金为人民币 100,000 元。

## 5. 核心公式

买入后的移动加权平均成本：

```text
（原数量 × 原平均成本 + 新数量 × 买入价格）÷ 新总数量
```

卖出已实现盈亏：

```text
卖出数量 ×（卖出价格 - 当前平均成本）
```

未实现盈亏：

```text
剩余数量 ×（模拟当前价格 - 平均成本）
```

## 6. 常见错误

- 使用 `double` 计算金额。
- 卖出后错误改变剩余持仓平均成本。
- 允许卖出数量超过持仓。
- 买入后现金可以变成负数。
- 交易记录成功但持仓更新失败。
- 页面没有标注价格是模拟数据。
- 只展示收益，不保存风险和退出条件。
