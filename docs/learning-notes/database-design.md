# 数据库设计学习笔记

## 解决什么问题

保存用户、课程、答题、错题、分析和虚拟投资数据，并保证一致性、查询效率和用户隔离。

## 为什么这样设计

- 用户私有表包含 `user_id`，便于数据库层隔离。
- 多对多关系使用中间表。
- 错题表保存用户维度聚合状态，而不是每次错误都创建重复错题。
- 金额使用 `DECIMAL(19,4)` 和 `BigDecimal`，避免浮点误差。

## 常见错误

- 所有字段都建索引。
- 使用 `double` 计算金额。
- 已发布后修改旧 Flyway 文件。
- 忘记联合唯一索引导致重复进度或重复错题。
- 用户私有查询遗漏 `user_id`。
