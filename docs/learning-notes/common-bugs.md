# 常见错误记录

## 环境

- Java 版本与项目要求不一致。
- Node.js 或 npm 未安装却继续生成前端代码。
- PowerShell 中 `node`、`npm` 不在 PATH。
- MySQL 数据库或用户未创建。

## 后端

- Spring Boot 3 依赖与旧版 Swagger 库不兼容。
- Security 默认拦截健康检查或 OpenAPI。
- 测试启动时强制连接本地 MySQL。
- Flyway 版本与 MySQL 支持模块不匹配。
- 全局异常把内部异常消息直接返回前端。

## 前端

- Axios baseURL 重复包含 `/api/v1`。
- 401 拦截器重复跳转。
- TypeScript 类型与后端字段不一致。
- 构建通过但开发代理配置错误。

## 数据库

- 修改已经执行的 Flyway 文件。
- 联合唯一索引缺失。
- 逻辑删除字段未参与唯一性设计。
- 金额字段使用浮点类型。

## 排查原则

1. 复现错误。
2. 保存完整错误信息。
3. 确认最近改动。
4. 定位最小失败边界。
5. 写测试或验证命令。
6. 进行最小修复。
7. 重新执行完整阶段验证。
