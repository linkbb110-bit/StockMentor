# StockMentor 项目章程

## 1. 项目背景

投资初学者通常面对知识来源碎片化、概念理解不牢、缺少练习反馈、容易追逐短期涨跌等问题。StockMentor 通过结构化课程、题库、错题本、AI 学习导师、公司分析训练和虚拟投资日志，帮助用户建立长期、可复盘的投资学习方法。

本项目同时作为 Java 后端实习作品，要求业务闭环完整、架构边界清晰、测试可验证、文档可讲解。

## 2. 项目目标

### 产品目标

- 建立从课程学习到练习、错题、复习和仪表盘反馈的完整闭环。
- 引导用户关注公司、财务、估值、竞争和风险，而非短期价格预测。
- 提供无真实资金风险的虚拟投资复盘工具。

### 技术目标

- 展示 Spring Boot 3、Spring Security、JWT、MyBatis-Plus、MySQL、Flyway、Redis 可选集成和单元测试能力。
- 展示数据隔离、事务、评分算法、统一异常、聚合统计和 AI 服务抽象能力。
- 形成可在面试中清楚解释的请求链路和设计决策。

## 3. 成功标准

V1.0 满足以下条件才视为项目成功：

- 用户能够注册、登录并安全访问自己的数据。
- 用户能够学习课程并保存进度。
- 用户能够提交题目并得到可验证的评分结果。
- 错题能够正确记录、复习和标记掌握。
- Mock AI 无需真实密钥即可完成概念解释和复习反馈。
- 用户能够完成公司分析训练。
- 用户能够用人民币 100,000 元虚拟资金记录模拟交易和复盘。
- 后端测试和前端构建实际通过。
- 数据库迁移可从空库执行。
- README、API、架构、数据库和学习文档完整。
- 项目不包含真实交易和荐股功能。

## 4. 主要利益相关者

- 产品使用者：投资初学者
- 项目开发者：Java 后端实习求职者
- 代码执行代理：Codex
- 项目评审者：面试官、教师或代码审阅者

## 5. 核心约束

- 第一版采用模块化单体，不采用微服务。
- 第一版不接实时行情。
- 第一版不做独立管理后台。
- 所有投资数据均明确标注为学习或模拟数据。
- AI 输出必须遵守投资教育边界。
