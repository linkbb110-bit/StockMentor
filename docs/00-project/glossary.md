# StockMentor 术语表

| 术语 | 定义 |
|---|---|
| Course | 一门完整课程，例如“投资基础入门” |
| Chapter | 课程中的章节 |
| Lesson | 可独立学习并标记完成的课时 |
| LearningProgress | 用户对某个课时的完成状态 |
| Quiz | 一组按业务组织的题目 |
| QuizAttempt | 用户一次完整的测验提交 |
| QuizAnswer | 一次测验中对单个题目的回答 |
| WrongQuestion | 用户维度的错题聚合记录 |
| KnowledgeWeakness | 根据错题或学习行为总结的薄弱知识点 |
| CompanyCase | 用于训练的原创虚拟公司案例 |
| CompanyAnalysis | 用户对公司案例的一次分析 |
| VirtualPortfolio | 使用虚拟资金的学习组合 |
| VirtualPosition | 虚拟组合中某个标的的当前持仓 |
| VirtualTransaction | 一次虚拟买入或卖出 |
| InvestmentJournal | 决策理由、风险、退出条件和复盘记录 |
| Mock AI | 不调用真实模型、可离线运行的固定规则实现 |
| 发布状态 | 内容是否允许普通用户读取 |
| 逻辑删除 | 通过字段标记删除，默认查询不返回已删除数据 |
