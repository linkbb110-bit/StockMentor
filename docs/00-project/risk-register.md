# StockMentor 风险登记册

| 风险 | 可能影响 | 应对方式 |
|---|---|---|
| 项目范围过大 | 延期、代码质量下降 | 按版本开发，每个版本独立计划和验收 |
| Codex 一次生成过多代码 | 接口不一致、测试缺失 | 每次只执行一个计划任务，频繁提交 |
| AI 输出越过教育边界 | 产生不适当投资建议 | 统一系统提示词、服务端安全规则和测试 |
| 实时行情 API 不稳定或收费 | 开发被外部依赖阻塞 | V1.0 不接行情，使用手动模拟价格 |
| 用户数据越权 | 严重安全问题 | 所有私有查询必须包含当前用户 ID |
| 金额计算精度错误 | 盈亏结果错误 | Java 使用 BigDecimal，数据库使用 DECIMAL(19,4) |
| 数据库结构频繁返工 | 迁移混乱 | 文档先行，Flyway 迁移只追加不修改已发布版本 |
| 测试流于形式 | 无法证明功能可靠 | 核心规则先写失败测试，再写实现 |
| 课程内容版权风险 | 无法公开展示 | 只写少量原创内容，不复制教材大段文字 |
| 密钥进入 Git | 安全泄露 | `.env` 忽略、只提交 `.env.example`、提交前扫描 |
| 前后端并行失配 | 联调失败 | API 文档先行，统一类型和错误码 |
| 过度架构 | 学习成本和维护成本上升 | 使用模块化单体，YAGNI，V1.0 不上微服务 |
