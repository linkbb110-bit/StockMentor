# StockMentor 项目范围

## 1. V1.0 范围内

- 邮箱密码注册登录
- BCrypt 密码加密
- JWT Access Token
- 当前用户资料和昵称修改
- Course → Chapter → Lesson 课程结构
- Markdown 课时正文
- 学习进度和下一节课程
- 单选、多选、判断和简答题
- 客观题自动评分
- 简答题 Mock AI 学习反馈
- 答题记录、正确率和错题本
- AI 学习导师统一接口及 Mock 实现
- 原创虚拟公司案例与分析训练
- 人民币 100,000 元虚拟投资组合
- 手动录入学习模拟价格
- 虚拟持仓、交易、盈亏和投资日志
- 学习仪表盘
- OpenAPI 文档
- Flyway 数据库迁移
- JUnit 5、Mockito 和关键集成测试
- 响应式 Vue 3 前端
- Docker Compose 作为 V0.9 工程完善内容

## 2. V1.0 范围外

- 真实交易和券商连接
- 实时行情和自动价格更新
- 个股买卖建议
- 短期涨跌预测
- 收益承诺
- 目标价和最佳买点
- 杠杆、融资、期权、做空
- 完整管理员后台
- 微服务、注册中心、网关和分布式事务
- 消息队列
- 邮箱验证码、找回密码、第三方登录
- Refresh Token
- 社区、评论、私信、关注
- 视频、音频和附件上传
- 付费订阅

## 3. 范围变更规则

新增功能必须满足以下流程：

1. 说明新增功能解决的问题。
2. 判断是否影响当前版本目标。
3. 分析数据库、接口、前端和测试影响。
4. 写入新的设计文档或 ADR。
5. 得到用户批准后进入实施计划。
6. 不得在当前开发任务中顺手加入未经批准的功能。
