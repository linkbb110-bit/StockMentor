# Definition of Done

一个阶段只有同时满足以下条件才算完成：

1. 计划中的代码和文档已经实际创建。
2. 没有未解释的范围外修改。
3. 后端代码实际编译通过。
4. 后端阶段测试实际通过。
5. 前端类型检查实际通过。
6. 前端生产构建实际通过。
7. 数据库迁移可以从空库顺序执行。
8. 核心接口经过实际验证。
9. DTO、VO 和 Entity 没有违规混用。
10. 用户数据查询满足当前用户 ID 隔离要求。
11. Git 中不存在真实密码、JWT 密钥或 API Key。
12. README 和阶段文档已经更新。
13. `docs/changelog` 已记录实际执行命令和结果。
14. 尚未完成内容已经明确列出。
15. 不使用“应该成功”“理论可行”代替实际结果。
