# 页面规格概览

## 登录页

- 邮箱、密码输入
- 表单校验
- 登录中状态
- 错误提示
- 跳转注册

## 注册页

- 邮箱、昵称、密码、确认密码
- 密码规则提示
- 注册后进入登录或直接登录，具体在 V0.2 设计中确定

## 仪表盘

- 学习进度
- 客观题正确率
- 待复习错题
- 薄弱知识点
- 最近学习记录
- 虚拟组合学习表现
- 下一步建议

## 课程中心与学习页

- 课程卡片
- 章节目录
- Markdown 正文
- 完成按钮
- 上一节和下一节

## 题库与错题本

- 题型展示
- 提交确认
- 评分结果
- 解析
- 错题状态
- 重新练习

## AI 导师

- 对话区域
- 当前课程上下文
- 教育用途提示
- 具体买卖问题的安全转向提示

## 公司分析

- 案例资料
- 十部分分析模板
- 保存草稿和提交
- 完整性、证据和逻辑反馈

## 虚拟投资日志

- 明显的模拟数据标签
- 组合资金和持仓
- 虚拟买卖表单
- 交易理由和风险
- 持有观察和事后复盘

## 视觉原则

- 专业、简洁、现代
- 不模拟证券交易终端
- 不用强烈红绿刺激强调涨跌
- 学习进度和风险提示优先于盈亏
